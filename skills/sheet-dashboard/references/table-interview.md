# 阶段 1：怎么带使用者设计表格

## 原则
1. **只放要手动填的栏位**。目标 5–8 栏，超过 10 栏就要砍。
2. **能算的不要填**：天数、是否逾期、完成率、本月几件、排名 → 全部交给 dashboard。
3. **能选的不要打字**：分类、状态、负责人、平台 → 下拉选单（选项 3–7 个）。
4. **一行 = 一件事**。不要设计成「一个月一个区块」或需要合并储存格的版面；一张表从上往下一直加就好。
5. **栏位名称短而清楚**（2–4 个字），不要缩写。
6. 有「完成」概念的表，一定要有一个状态下拉选单（含「完成」）或一个「完成」打勾栏，dashboard 才算得出进度。
7. 有截止日的事，加一个日期栏，dashboard 才能抓逾期 / 快到期。

## 提问顺序（一次一题）
1. 「你想用这个表格追踪什么？」→ 听不出来就给下面的范例选。
2. 「现在平常怎么记？（脑袋 / 笔记本 / WhatsApp / Excel…）有哪些资讯是你每次都会写的？」→ 这些就是栏位候选。
3. 「谁会填这张表？只有你，还是同事也会填？」→ 多人填就加「负责人」下拉选单。
4. 「打开 dashboard 的时候，你最想一眼看到什么？」给选项：
   - 哪些事逾期了 / 快到期
   - 整体完成了多少 %
   - 每个分类（店 / 平台 / 客户）各自的进度
   - 这个月做了多少、跟上个月比
   - 金额加总（营收、花费）
5. 「有没有不想看到、看了会烦的东西？」
6. 秀出栏位表 → 「这样可以吗？」

## 常见范例（给不知道怎么开始的人挑）

### 1. 工作待办 / 专案追踪
| 栏位 | 类型 | 范例 |
|--|--|--|
| 项目 | 文字 | 新菜单拍摄 |
| 分类 | 下拉 | 门市 A / 门市 B / 行销 / 其他 |
| 负责人 | 下拉 | 我 / 同事 A / 外包 |
| 截止日 | 日期 | 15/11/2026 |
| 状态 | 下拉 | 未开始 / 进行中 / 等回复 / 完成 |
| 最新进度 | 文字 | 摄影师已确认时间 |
Dashboard：逾期、7 天内到期、各分类进度、完成率。

### 2. 社群内容排程
| 栏位 | 类型 | 范例 |
|--|--|--|
| 内容标题 | 文字 | 周末优惠 Reel |
| 平台 | 下拉 | IG / FB / TikTok / 小红书 |
| 类型 | 下拉 | Reel / 图文 / 限动 |
| 预计发布日 | 日期 | 08/11/2026 |
| 状态 | 下拉 | 构思 / 拍摄 / 剪辑 / 待发布 / 已发布 |
| 连结 | 网址 | https://… |
Dashboard：本周要发的、卡在哪个阶段最多、各平台本月发了几篇。

### 3. 客户 / 销售跟进
| 栏位 | 类型 | 范例 |
|--|--|--|
| 客户 | 文字 | ABC 公司 |
| 来源 | 下拉 | IG / 介绍 / 网站 / 路过 |
| 下次跟进日 | 日期 | 05/11/2026 |
| 阶段 | 下拉 | 新名单 / 已联络 / 报价中 / 成交 / 没兴趣 |
| 金额 (RM) | 数字 | 3,500 |
| 备注 | 文字 | 要等老板回国 |
Dashboard：今天要跟进的、各阶段人数、成交金额、成交率。

### 4. 活动 / 合作对象（KOL、供应商）
| 栏位 | 类型 | 范例 |
|--|--|--|
| 名字 | 文字 | @foodie.my |
| 类型 | 下拉 | KOL / 媒体 / 供应商 |
| 日期 | 日期 | 12/11/2026 |
| 状态 | 下拉 | 邀约中 / 已确认 / 已完成 / 取消 |
| 费用 (RM) | 数字 | 500 |
| 成果连结 | 网址 | https://instagram.com/… |
Dashboard：本月合作几位、总花费、还没交成果的。

### 5. 库存 / 物品借用
| 栏位 | 类型 | 范例 |
|--|--|--|
| 物品 | 文字 | 拍摄灯 |
| 类别 | 下拉 | 器材 / 道具 / 文具 |
| 数量 | 数字 | 2 |
| 借用人 | 下拉 | … |
| 归还日 | 日期 | 03/11/2026 |
| 已归还 | 打勾 | ☐ |
Dashboard：逾期没还的、每个类别数量。

## 对应到 Code.gs CONFIG
- 每一栏 → `columns` 里一个 `{ key, label, type, options? , width? }`（key 用英文小写，label 就是 Sheet 表头）
- `roles.title` = 名称那栏；`roles.group` = 用来分组的下拉选单；`roles.date` = 截止 / 预计日期；`roles.status` = 状态下拉；`roles.doneStatus` = 哪些状态算完成；没有状态但有「完成」打勾栏就用 `roles.doneCheckbox`
- 没有的角色填 `null`，dashboard 会自动隐藏对应区块
- 需要金额加总、每月统计等模板没有的东西，就在 `getDashboardData` 多回传资料，并在 `Index.html` 加区块
